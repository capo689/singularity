Install path

Connect WordPress, then let ChatGPT run the first checks.

The first session should confirm the connection, then let ChatGPT inspect the site, review competitors, choose focused keywords and prepare one governed SEO plan before any public change.

Setup steps

Install the pluginUpload and activate the Singularity SEO WordPress plugin.
Open the dashboardConfirm the hosted connection shows as verified.
Connect ChatGPTCopy the connection command from WordPress and paste it into the Singularity SEO ChatGPT app.
Run verificationAsk ChatGPT to confirm the site, technical health, analytics connection, rank-tracking limits and reporting surfaces.
Build the SEO planAsk for a competitive review, keyword strategy and one governed full-site batch proposal.

Launch verification prompt

For my connected Singularity SEO site, run a read-only launch verification. Read status, getting started, capabilities, reports list, operating manual/governance, technical health, visibility config, visibility metrics, proposal queue and latest change history. Confirm the Controller version, plugin version, site URL, managed pages, capabilities, reporting tools, GSC state, rank provider state, three-keyword limit, SerpApi daily limit, technical health, protected governance and proposal queue. Do not apply changes. Do not create SEO proposals. Do not approve anything. Do not roll back anything. Do not run rank refreshes. Do not create visibility snapshots. Do not call SerpApi. Return a concise pass/fail report and highlight any issues.

Good first prompts

Baseline

Run my baseline SEO report and explain what you found.

Strategy

Review competitors in my category, explain the SEO opportunity and suggest the strongest three launch keywords.

Plan

Build a full-site SEO plan for search and AI discovery as one batch proposal for my approval. Do not apply it yet.
