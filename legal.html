Customer safety

Singularity SEO stores only what it needs to operate the SEO control plane.

This page explains what Singularity SEO processes, why it processes it, who receives it, how long operational records are kept and how customers can request support or deletion.

Data processed

Connection

Customer/site ID, site URL, hosted connection record and authenticated ownership mapping.

SEO operations

Managed page registry, setup scans, health snapshots, proposals, applied changes and rollback records.

Visibility

Search Console property, ranking domain, tracked keywords and measured search data when connected.

Purpose and recipients

Singularity SEO uses this data to verify site ownership, run SEO audits, prepare governed SEO proposals, apply approved SEO changes, restore prior controlled SEO state, generate reports and show connected search visibility.

Hosted controller

Stores customer/site connection records, managed SEO state, proposals, reports, visibility configuration and change history.

WordPress site

Receives approved controlled SEO updates and returns site status, registry, live head and health data.

Connected providers

Google Search Console and rank providers are used only when connected for reporting or explicitly requested rank checks.

Product scope

Singularity SEO is not a full WordPress administration tool. It does not manage hosting, billing, themes, menus, page body content or unrelated WordPress data.

Can read

Status, managed pages, protected governance, technical health, visibility configuration, reports and change history.

Can propose

SEO titles, descriptions, social metadata, campaign SEO and batch plans for approval.

Can change

Approved controlled SEO metadata and approved restores to prior controlled state.

Search data

Google Search Console may connect before Google returns measurable rows. That is a valid pending state. Rank refreshes may consume one provider search per tracked keyword.

Standard WordPress launch plan: - Up to three tracked keywords - Server-side daily rank-search limits - No ranking, traffic, revenue or AI/search placement guarantees

Retention and controls

Connection records, reports, proposals, applied changes and rollback records are retained while the customer keeps the site connected so the product can audit work and restore prior controlled state. Customers can disconnect the ChatGPT app, remove the WordPress plugin or request hosted data deletion through support.

Data not requested

Singularity SEO does not ask for payment-card data, government identifiers, health information, WordPress passwords, OAuth secrets, API keys, MFA codes, full ChatGPT transcripts or unrelated WordPress user records.

Removal and support

Customers can disconnect the ChatGPT app, remove the WordPress plugin or request hosted data deletion through the published support channel. Do not send passwords, private keys or OAuth secrets in support requests.
